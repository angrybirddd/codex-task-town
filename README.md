# Codex Task Town — 共享像素工作室

一个只读、本地优先的 Codex Desktop 任务看板。每个任务会话是一位像素居民，普通程序采集事件，浏览器播放动画；看板不调用模型、不需要 API Key。

**当前版本：0.3.0。**第一阶段只做人员／任务工作状态。营地与村庄的「项目建设进度」是第二阶段，等工作室完成真实桌面联调后再开发。工作事件数量不等于项目完成度。

## 运行

需要 Node.js 22 或更高版本；macOS / Linux 安装脚本。不需要 `npm install`。

```bash
npm start
```

打开 `http://127.0.0.1:4317`。`/?demo=1` 是显式的模拟演示，不代表真实任务。没有事件时显示空工作室，不会用演示数据冒充实时状态。

网页有窗边长台、共享桌、白板、测试区、阅读角、咖啡角和沙发。点击居民打开档案，支持任务搜索、状态筛选、分页、浏览器本地昵称。手机上可横向浏览场景，同时通过可读的列表查看每位居民。动画可暂停，并响应系统的减少动态效果设置。

## 接入 Codex Desktop

先在终端进入本项目目录：

```bash
npm run hooks:preview
npm run hooks:install
```

在 Codex 桌面应用里审核、信任新增或变更的 Hooks，然后开始一个新的任务或回合。安装器保留其他 Hooks 并备份已有 `hooks.json`；监控脚本复制到内容指纹目录，脚本变动会改变配置中的路径，不能静默沿用旧的信任。

```bash
npm run probe           # 合成事件自检，不代表 Desktop 信任已通过
npm run hooks:uninstall # 仅移除本项目标记的 Hook 条目
```

默认文件位置：

- `~/.codex/hooks.json`：用户级 Hook 配置；遵循 `CODEX_HOME`。
- `~/.codex-task-town/integration/<fingerprint>/`：固定路径的采集脚本。
- `~/.codex-task-town/spool/`：仅包含规范化事件的本地队列。
- `~/.codex-task-town/state.json`：任务快照与重放去重标识。

更换 Node 安装路径后需重新运行安装器。使用 `TOWN_DATA_DIR` 时，安装和启动服务必须指向同一个目录。已有任务等下一次事件发生后才出现，不扫描历史对话。

## 数据与状态规则

```text
Codex Desktop → 本地 Hook → 规范化事件文件 → 单实例采集器 → SSE → 浏览器动画
```

`PreToolUse` 区分编码、读取、测试和普通命令；`PostToolUse` 只核对该工具是否返回，不代表整个任务结束。审批请求优先突出；其他并行工具的返回不会清掉它。`Stop` 只标记「观察到本轮收尾」，不标记「需求已完成」。收尾之后同回合的异步事件可能迟到，不能作为新工作的证明；等待新的回合／提示信号确认继续。长时间无信号、断线或保存异常时，显示状态待确认，而不是休息。

每个独立会话具有稳定身份。携带 `agent_id` 的事件和子任务生命周期使用独立身份，保留父任务关系；未带子任务标识的工具事件只能按来源会话归类，**不保证识别所有内部子代理操作**。规则识别不了的命令显示一般活动，不编造工作含义。

人物位置与短期工具动作分离。居民先分配到固定逻辑房间，再过滤；跨页搜索也不会把不同房间的居民挤到同一座位。等待和状态未知保持位置。只有明确 idle 的输入才进入休息区域。当前纯 Hooks 不能权威证明每一刻的 idle；因此真实任务可能长时间显示「收尾／状态待确认」，不能把演示中的休息状态当作已验证的桌面能力。

## 隐私与开销

默认不保存原始提示词、命令、代码、工具输出、绝对路径或原始会话标识。角色通过本地规则判断，任务身份使用哈希；**哈希不是匿名化或加密保证**。只保存短模板文案和有限历史。

```bash
npm run hooks:install -- --filenames
```

上述选项显式开启文件 basename 显示；常见敏感名称会被过滤，但过滤不是完整 DLP。昵称默认仅存在当前浏览器，不同步给其他查看者。请勿把秘密写进共享昵称或文件名。

没有额外模型调用，不返回 `additionalContext`、审批决定或改写工具参数。高频 `PreToolUse`、`PermissionRequest`、`PostToolUse` 采用异步脚本，避免逐次等待记录完成；少量生命周期 Hook 保持同步以保留开始／收尾边界。内部约 800ms 看门狗，配置 1 秒超时，尽力退出 0；**不等于零延迟、零系统开销或任何故障都不可能影响宿主**。异步事件可能乱序、取消或缺失；不能据此承诺完整追踪。输入超过 1MiB、队列约满 2000 项或存储不可用时，丢弃监控数据而非工作数据。角色动画只消耗浏览器资源。

采集器每批先落盘快照与去重标识，再删除对应队列文件。写失败保留队列；第二个服务不能同时消费相同目录。历史和任务数有上限：200 位居民、每位 16 条历史，每页 8 位。关联表有界；标识缺失、相同并行命令歧义或超出容量时显示待确认，不默默猜测。工具失败也会过期。`npm run probe` 的居民明确标注「自检」，计数与非探针事件分开；旧版本来源不明的记录标注「历史记录」。这些标签不是来源认证，任何同系统用户仍能构造事件。这不是永久审计日志。

### 故障恢复

正常 `Ctrl+C` 会关闭服务并释放目录锁。强杀或异常退出可能留下 `collector.lock`；程序不再凭 PID 自动抢占遗留锁，因为检查与删除之间可能发生竞争。先确认指向该目录的所有采集器均已退出，保留快照和队列，再处理遗留锁、重新启动；不要在另一个服务仍运行时删除它。损坏、非普通文件或不支持的快照会阻止启动，并保留原文件供检查，不能直接覆盖成空工作室。恢复后旧的活跃状态显示待确认，直到收到新证据。

## 局域网只读分享

默认只绑定本机。不建议暴露公网。在可信网络使用足够随机的查看令牌：

```bash
export TOWN_VIEW_TOKEN="$(node -e 'console.log(require("node:crypto").randomBytes(32).toString("hex"))')"
TOWN_HOST=0.0.0.0 npm start
```

其他人用你的局域网 IP 和端口打开网页，在「接入指南」输入令牌。身份凭证放在请求头，不放在 SSE URL 查询参数。HTTP 不加密流量；不可信网络应使用受控 HTTPS 反向代理或可信隧道。服务有严格 Host / Origin 限制，默认不支持随意配置的代理域名。网页 API 只读，不提供批准命令或调度任务接口。

常用变量：`PORT`（4317）、`TOWN_HOST`（127.0.0.1）、`TOWN_DATA_DIR`、`TOWN_VIEW_TOKEN`、`TOWN_STALE_MS`（120000）。

## 测试与边界

```bash
npm test           # Node 单元、状态机、磁盘、HTTP/SSE、安装链路、强杀恢复
# 以下需要 Python 3.13、Playwright 1.57.0 和 Chromium，仅测试工具需要安装：
python3 -m pip install playwright==1.57.0
python3 -m playwright install chromium
npm run test:ui    # 内存页面与模拟流的 UI 回归，不是端到端
npm run test:e2e   # 正常浏览器访问真实服务，再执行已安装 recorder；不允许假通过
```

已有 Chromium 时可设置 `CHROMIUM_PATH`；省略时使用 Playwright 安装的版本。浏览器 E2E 仍不启动 Codex，不代表 Hook 信任与真实 Desktop 事件覆盖已经验证。

验证详情见 `docs/VALIDATION.md`。第一性原理审查及证据矩阵见 `docs/FIRST_PRINCIPLES_REVIEW.md`，前一版审查保留在 `docs/REVIEW.md`。当前本地 85 项 Node 测试和 14 项模拟 UI 检查通过；真实浏览器访问本地服务被本次执行环境策略拦截，**这项测试未通过，不用模拟测试代替它**。CI 配置包含 Linux/macOS Node 测试，以及 Linux 真实浏览器 E2E；配置存在不等于执行成功，以该提交的 Actions 结果为准。

升级后重新运行 `hooks:preview`、`hooks:install` 并在 Desktop 审核信任变更。Hook 的发行版行为依据 OpenAI 官方文档：<https://learn.chatgpt.com/docs/hooks>。支持范围和字段可能变化；安装后必须在你的桌面版本上验证发起任务、工具执行、审批、中断与收尾。不要跳过 Hook 信任或权限确认。
