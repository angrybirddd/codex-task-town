## 尚未验证 / 未实现

- 用户 Mac 上真实 Codex Desktop：新增 Hooks 的信任、具体版本字段、审批、中断、会话收尾和多任务事件覆盖。
- 未携带 `agent_id` 的工具事件不能保证归属于正确子任务；没有解析不稳定的 transcript。
- 普通 Hook 静默不能证明空闲。真实界面仍可能显示“状态待确认”，这是保守设计。
- 持续运行、机器断电和复杂网络反向代理部署没有完整验证。默认仅本机，不建议公网裸露。

## 本机接入验收

先运行 `npm start` 打开网页，再预览/安装 Hooks，在 Codex Desktop 审核信任后开启新任务或新回合。实际观察：两个并行会话不串状态；修改文件显示编码；审批不显示休息；中断不继续假装工作；断开采集器显示未知；恢复后等待新信号。看到真实任务事件，才算接入链路有数据。
