WELCOME TO TASK TOWN

把 Codex 接进小镇

在项目目录运行以下命令。安装前可以预览修改，已有 Hooks 会保留并备份。

npm run hooks:preview
npm run hooks:install
npm start

回到 Codex 桌面应用，审核并信任新增的 Hooks，再开启一个新任务或回合。旧任务要等到新的事件触发才会出现。

已连接网页 ≠ Codex 已接入。看到真实任务事件，才说明链路有数据。没有新日志不会被判定为休息。

让所有查看者看到任务名称

管理员可在看板服务的数据目录创建 labels.json，用居民档案中的完整任务 ID、项目 ID 映射为允许公开的名称。重启服务后生效；格式见 README 的“共享任务名称”。不会读取原始提示词，也不增加模型调用。

自检

npm run probe

这会发送合成测试事件，只验证采集链路，不代表已验证桌面应用的 Hook 信任。

局域网访问

服务默认只允许本机。共享时需显式设置监听地址和至少 24 字符的查看令牌；不要直接暴露到公网。详细步骤见 README。

让任务容易辨认

填写简短明确的任务目标，例如“修复登录权限”。这里的名称仅在此浏览器生效；多人共享名称请配置服务端 labels.json，详见接入指南。
